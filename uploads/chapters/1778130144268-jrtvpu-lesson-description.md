# What is Python?

Python is a high-level programming language that is simple and easy to learn.

It was created by Guido van Rossum and released in 1991.

Python is one of the most popular programming languages in the world because of its clean syntax and powerful features.

---

# Features of Python

- Easy to read and write
- Beginner-friendly
- Open-source
- Cross-platform
- Large community support
- Used in many industries

# Installing Python

## Step 1: Download Python

Go to the official Python website:

https://www.python.org/

Download the latest version of Python for your operating system.

---

## Step 2: Install Python

Open the installer and follow these steps:

- Check the option:
  `Add Python to PATH`

- Click:
  `Install Now`

After installation is complete, Python will be ready to use.

---

# Installing VS Code

VS Code is a popular code editor used for writing Python programs.

Download VS Code from:

https://code.visualstudio.com/

After installing VS Code:

1. Open VS Code
2. Go to Extensions
3. Search for "Python"
4. Install the Python extension

# Your First Python Program

Create a new file named:

```text
main.py
```

Write the following code:

```python
print("Hello World")
```

---

# Running the Python Program

Open the terminal and run the following command:

```bash
python main.py
```

Output:

```python
Hello World
```

This is your first Python program.

---

# Understanding the print() Function

The `print()` function is used to display output on the screen.

Example:

```python
print("Welcome to Python")
print("I am learning coding")
```

Output:

```python
Welcome to Python
I am learning coding
```

---

# Comments in Python

Comments are used to write notes inside the code.

Python ignores comments while running the program.

Example:

```python
# This is a comment
print("Hello")
```

---

# Python Syntax Rules

- Python is case-sensitive
- Proper indentation is important
- Use meaningful variable names
- Follow clean coding practices

Correct Example:

```python
user_name = "Rahul"
```

Incorrect Example:

```python
UserName="Rahul"
```

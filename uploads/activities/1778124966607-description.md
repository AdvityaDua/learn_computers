# Class Activities — Lesson 1: Introduction to Python

## Activity 1: Introduction Discussion

### Objective
Understand what Python is and where it is used.

### Instructions
Discuss the following questions in class:

1. What is programming?
2. Why do people learn Python?
3. Name some real-world applications of Python.
4. Which companies use Python?

### Expected Outcome
Students should understand the importance and uses of Python.

---

# Activity 2: Installing Python and VS Code

## Objective
Set up the Python programming environment.

## Instructions

Students should:

1. Download Python from:
   https://www.python.org/

2. Install Python on their computer.

3. Download and install VS Code.

4. Install the Python Extension in VS Code.

### Teacher Task
Verify that each student can:
- Open VS Code
- Create a Python file
- Run a simple Python program

---

# Activity 3: Write Your First Program

## Objective
Learn how to write and run a basic Python program.

## Instructions

Create a file named:

```text
main.py
```

Write the following code:

```python
print("Hello World")
```

Run the program using:

```bash
python main.py
```

### Expected Output

```text
Hello World
```

---

# Activity 4: Practice Using print()

## Objective
Understand how the `print()` function works.

## Instructions

Write programs for the following:

### Program 1

```python
print("Welcome to Python")
```

### Program 2

```python
print("My name is Alex")
print("I am learning Python")
```

### Program 3

```python
print("Python")
print("Programming")
print("Course")
```

---

# Activity 5: Working with Comments

## Objective
Learn how to use comments in Python.

## Instructions

Write the following program:

```python
# This is my first comment
print("Comments are useful")
```

Now create your own comment and print statement.

---

# Activity 6: Fix the Errors

## Objective
Understand correct Python syntax.

## Instructions

Correct the errors in the following programs.

### Question 1

```python
Print("Hello")
```

### Question 2

```python
print(Hello World)
```

### Question 3

```python
print"Python"
```

# Activity 7: Class Challenge

## Objective
Improve confidence in writing Python programs.

## Challenge

Write a program that prints:

```text
Welcome to the Coding Class
Today we are learning Python
```

Rules:
- Use at least 2 `print()` statements
- Add one comment in the program

---

# Activity 8: Pair Programming Activity

## Objective
Encourage teamwork and problem-solving.

## Instructions

Students will work in pairs.

Each pair must:
1. Create a greeting program
2. Add comments
3. Use multiple `print()` statements
4. Run the program successfully

Example:

```python
# Greeting Program
print("Hello Students")
print("Welcome to Python")
```

---

# Activity 9: Quick Quiz

## Questions

1. Who created Python?
2. Which function is used to display output?
3. What is the purpose of comments?
4. What is the correct file extension for Python files?
5. Is Python case-sensitive?

---

# Activity 10: Mini Practice Task

## Objective
Practice independently.

## Task

Create a Python program that prints:
- Your name
- Your favorite subject
- Why you want to learn Python

Example:

```python
print("My name is John")
print("My favorite subject is Computer Science")
print("I want to learn Python to become a developer")
```

---

# Learning Outcome

After completing these activities, students will be able to:
- Understand Python basics
- Write simple Python programs
- Use the `print()` function
- Add comments in Python
- Run Python files successfully
- Follow basic Python syntax

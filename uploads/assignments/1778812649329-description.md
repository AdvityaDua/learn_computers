# Assignment: Introduction to Python

## Objective

The purpose of this assignment is to help students practice the basics of Python learned in Lesson 1.

Students will:
- Write their first Python programs
- Use the `print()` function
- Understand comments
- Practice basic Python syntax

---

# Instructions

Complete all the tasks given below.

Create a new Python file named:

```text
assignment1.py
```

Write the required programs inside the file.

---

# Task 1: Print a Simple Message

Write a Python program that prints the following message:

```text
Welcome to Python Programming
```

Example:

```python
print("Welcome to Python Programming")
```

---

# Task 2: Print Multiple Lines

Write a program that prints the following lines:

```text
My name is John
I am learning Python
Python is easy to learn
```

---

# Task 3: Use Comments

Write a program that includes:
- One single-line comment
- One `print()` statement

Example:

```python
# This is my first Python comment
print("Learning Python")
```

---

# Task 4: Create Your Own Greeting Program

Write a program that prints a greeting message for users.

Example Output:

```text
Hello Students
Welcome to the Python Course
```

You may create your own custom greeting message.

---

# Task 5: Practice Python Syntax

Write a program using:
- Proper indentation
- Meaningful text
- Correct Python syntax

Example:

```python
print("Python Practice Program")
```

---

# Requirements

Students must:
- Submit a `.py` file

- Use correct Python syntax
